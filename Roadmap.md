# ROADMAP.md

# Student Toolkit V1 - Product Roadmap

Version: 1.0 (Final)

------------------------------------------------------------------------

# Product Vision

Membangun Student Toolkit sebagai platform produktivitas akademik
berbasis web yang menggabungkan document tools dan AI study tools dalam
satu ekosistem.

------------------------------------------------------------------------

# Current Tech Stack

Frontend - React - Inertia.js - Tailwind CSS

Backend - Laravel 12

Database - MySQL

Deployment - Ubuntu + Nginx

------------------------------------------------------------------------

# Release Strategy

## V1 (MVP)

Target: Menyediakan fondasi produk yang stabil dan siap digunakan
publik.

### Authentication

-   Register
-   Login
-   Logout
-   Profile

### Document Tools

-   PDF → Word
-   Word → PDF
-   Merge PDF
-   Split PDF
-   Compress PDF
-   Image → PDF
-   PDF → Image

### AI Study

-   Audio → Text
-   AI Summary
-   Quiz Generator

### User Features

-   History
-   Dashboard
-   Profile

Success Criteria - Semua 10 fitur berjalan stabil. - UI responsif. -
Deployment berhasil di VPS.

------------------------------------------------------------------------

# V1.1

Target: Meningkatkan pengalaman pengguna.

Features - Drag & Drop lebih baik - Progress processing - Download
manager - Dark Mode - Multi-language - Performance optimization - Better
error messages

------------------------------------------------------------------------

# V1.5

Target: Menambah fitur akademik.

Features - OCR - Flashcards - Notes - Workspace - Favorite Tools -
Recent Files - Search History

------------------------------------------------------------------------

# V2

Target: Membangun ekosistem belajar.

Features - Chat PDF - AI Explain - AI Rewrite - AI Translator - Citation
Generator - Reference Manager - Study Planner - Calendar

------------------------------------------------------------------------

# V3

Target: Kolaborasi dan produktivitas.

Features - Team Workspace - Shared Documents - Shared Notes - Realtime
Collaboration - Notifications - Activity Feed

------------------------------------------------------------------------

# V4

Target: Platform lengkap untuk mahasiswa dan fresh graduate.

Features - Resume Builder - Portfolio Builder - Interview Preparation -
Career Dashboard - Internship Tracker - Job Toolkit

------------------------------------------------------------------------
